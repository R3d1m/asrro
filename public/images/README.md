# ASRRO Website Image Assets Directory

Drop your photos into these respective subdirectories. The website will automatically reference and load them.

---

## 📂 Folder Structure & File Naming Conventions

### 1. `public/images/projects/` (Fleet & Hardware Projects)
Recommended ratio: **16:9** or **4:3**, minimum width: 1200px.
- `starlap.jpg` (or `.png` / `.webp`) → **STARLAP Genesis-I Sounding Rocket**
- `titan.jpg` → **Project TITAN Planetary Rover**
- `telescope.jpg` → **Handcrafted Deep Sky Telescope**
- `orion.jpg` → **Project ORION CubeSat Bus**

### 2. `public/images/advisors/` (Faculty Advisory Board)
Recommended ratio: **4:5** or **1:1** (vertical academic portraits), minimum width: 600px.
- `sajal-banik.jpg` → **Dr. Sajal Chandra Banik** (Mechanical Engineering)
- `ahsan-ullah.jpg` → **Dr. Muhammad Ahsan Ullah** (EEE)
- `mahbubul-alam.jpg` → **Dr. Mahbubul Alam** (Mechanical Engineering)
- `yunus-ahmed.jpg` → **Dr. Yunus Ahmed** (Chemistry)

### 3. `public/images/achievements/` (Competitions & Trophies)
Recommended ratio: **16:9**, minimum width: 1000px.
- `nasa-world-champion.jpg` → **Global Space Challenge 2025 World Champion** (NASA Patronage)
- `starlap-launch.jpg` → **STARLAP Genesis-I Level-1 Rocket Milestone**
- `robotics-champion.jpg` → **National Autonomous Robotics Championship**
- `optics-award.jpg` → **National Space Science Festival Innovation**

### 4. `public/images/press/` (Media Clippings & Broadcasts)
Recommended ratio: **16:9**, minimum width: 800px.
- `daily-star.jpg` → **The Daily Star** Newspaper clipping / headline
- `prothom-alo.jpg` → **Prothom Alo** Article clipping
- `cuet-bulletin.jpg` → **CUET Media Portal** Announcement

### 5. `public/images/branding/` (Club Emblems & Logos)
- `asrro-logo.png` → Official ASRRO Crest/Emblem (transparent PNG)
- `cuet-logo.png` → Official CUET Logo
